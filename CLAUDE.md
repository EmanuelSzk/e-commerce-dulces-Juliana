# Convenciones del proyecto

## Commits

Los commits de este repositorio **no deben registrar colaboración de ninguna herramienta ni asistente**.

- No agregar líneas `Co-Authored-By:` de ningún tipo.
- No agregar firmas, créditos ni menciones tipo "Generated with ..." en mensajes de commit.
- Lo mismo aplica a descripciones de pull requests.

El mensaje de commit debe contener únicamente la descripción del cambio.
